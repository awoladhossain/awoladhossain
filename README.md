## 🚀 Featured Projects

### 🚗 RideTrack BD — Ride-Sharing Platform *(In Progress)*
> A production-grade, full-stack ride-sharing platform built from scratch to master scalable real-time architectures.

- **Architecture:** Hybrid setup consisting of a Node.js ecosystem and high-performance **Go microservices** handling a dynamic pricing engine.
- **Geospatial & Real-time:** Utilizes **PostgreSQL with PostGIS** extensions for spatial query optimization and **WebSockets (Socket.IO)** for live driver-passenger location updates.
- **Infrastructure:** Containerized using **Docker Compose** with background jobs managed via asynchronous worker patterns, fully automated using **GitHub Actions CI/CD** pipelines for cloud deployments.

### 🏢 TurfSync / ASG SHOP™ — Enterprise Backend Systems
> Advanced backend applications optimized for multi-level business logic, data consistency, and heavy multi-user hierarchies.

- **Clean Coding:** Built with **NestJS, PostgreSQL, and Prisma ORM** implementing strong **Role-Based Access Control (RBAC)** matrices and centralized exception handling filters.
- **Reliability:** Integrated runtime schema validations via **Zod** ensuring absolute data integrity, alongside asynchronous task processing using **BullMQ & Redis** to eliminate main-thread bottlenecks.
- **Performance:** Successfully optimized legacy query bottlenecks, bringing down high-latency responses to under 200ms in production environments.

### 🤟 SignVision — AI Sign Language Recognition System
> Published research at **Springer BIM 2025**

- Designed an AI pipeline for real-time Bangla sign language detection using **YOLOv8 and OpenCV**.
- Handled a custom ML pipeline trained and evaluated on **10,000+ data samples**.
- Wrapped the core system into a containerized REST API optimized for **GPU-accelerated** inference tracking.
